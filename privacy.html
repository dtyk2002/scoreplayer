악보재생 개인정보처리방침

시행일: 2026년 11월 20일

1. 모으는 정보

악보재생은 개발자의 서버를 운영하지 않으며, 사용자의 개인정보를 개발자에게 보내거나 모으지 않습니다. 악보 파일과 설정은 사용자의 기기 안에 저장됩니다.

2. 구글 드라이브 사용

  • 사용자가 ‘구글 드라이브 연결’을 직접 누르고 구글에서 허용한 경우에만 사용합니다.
  • 권한은 drive.file(이 앱이 만든 파일만 보기·쓰기)만 요청합니다. 사용자의 다른 드라이브 파일은 보거나 고치거나 지울 수 없습니다.
  • 앱은 사용자 드라이브의 ‘악보재생 동기화’ 폴더에 악보 파일과 동기화 정보(state.json: 악보 목록, 저장 구간, 삭제 기록)를 저장하고 읽습니다. 이 데이터는 사용자의 기기와 사용자 본인의 구글 드라이브 사이에서만 오가며, 다른 곳으로 보내지 않습니다.
  • 구글 연결 정보(갱신 토큰)는 사용자의 기기 안(휴대폰 앱 저장소, PC의 사용자 폴더)에만 저장됩니다.
  • 앱은 드라이브의 파일을 삭제하지 않습니다.
  • Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

3. 연결 해제

앱의 ‘연결 끊기’ 또는 구글 계정의 서드 파티 액세스 관리에서 언제든 연결을 해제할 수 있습니다. 드라이브의 ‘악보재생 동기화’ 폴더는 사용자가 직접 지울 수 있습니다.
